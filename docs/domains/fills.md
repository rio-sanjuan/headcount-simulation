# Fills

::: hcsim.engine.fills

## Data findings

- External fill hazards by requisition age recover the world's: 0.123, 0.253, 0.272, and 0.230
  at ages 0, 1, 2, and 3 or more months, against the truth's 0.149, 0.294, 0.288, and 0.230 on
  the medium world.
- A boosted model beats the null arm on both worlds (log loss 0.4927 to 0.4125 on medium).
