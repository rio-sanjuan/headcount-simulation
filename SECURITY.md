# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue.

You can expect an acknowledgement within a week.

## Reporting sensitive content

All data in this repository is meant to be synthetic. If you find anything that looks like real personal, workforce, compensation, or proprietary information, in the code, the docs, an issue, or a CI artifact, please report it the same private way so it can be removed quickly.

## Scope

The project runs locally and processes only data it generates. It has no network service, and it stores no credentials.
